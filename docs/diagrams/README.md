# Diagramas y Modelos del Sistema

Este directorio almacena los artefactos gráficos y modelos de partida y evolución del sistema:

- **Casos de Uso:** Modelo de casos de uso inicial del cliente y sus refinamientos.
- **Modelo de Dominio / Clases:** Diagramas estructurales de entidades y relaciones del sistema.
- **Diagramas de Secuencia o Componentes:** Trazabilidad de interacciones complejas.

> Todos los cambios en el modelo de dominio implementado en código deben verse reflejados en los diagramas de este directorio.
